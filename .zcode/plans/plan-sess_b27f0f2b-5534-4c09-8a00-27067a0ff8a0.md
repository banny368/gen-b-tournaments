# Full App Audit — Function + UI, Find & Fix All Bugs

## Goal
Drive the live app (https://gen-b-tournaments.vercel.app) end-to-end in a real browser like a player and an admin would, catalog every functional bug and UI problem, then fix each one properly (root cause first) and redeploy.

## Phase A — Browser Audit (find the bugs)
Use the browser automation skill to walk the entire app with screenshots + console-error capture:
1. **Public flow:** home (hero/cards/games), tournaments list + filters, tournament detail, legal pages, language switch (en/hi/gu)
2. **Player flow:** register → login → profile (DOB save) → rewards (daily + demo credits) → wallet (balances + demo deposit) → join tournament → my matches → leaderboard → notifications → chat (send message) → claims (create)
3. **Admin flow:** dashboard → create tournament → deposits queue → withdrawals → users → settings/flags → audit log
4. **UI quality pass on every page:** layout breakage, spacing/contrast problems, missing loading/empty/error states, mobile-width rendering (375px), desktop (1440px), dead buttons, untranslated strings, console errors

Output: numbered bug list with severity (crash / broken flow / UI polish), each with screenshot evidence.

## Phase B — Fix (systematic-debugging per bug)
- For each bug: reproduce → root cause → minimal fix → verify (no symptom-patching)
- Known suspects already on my list (audit will confirm): admin sidebar hidden entirely on mobile (no nav to admin on phones), no forgot-password flow, room-credentials error display, tournament results form using raw UUIDs, possible empty-state gaps
- Group fixes into one deploy; keep commits clean

## Phase C — Verify & Ship
- Re-drive every fixed flow in the browser (before/after screenshots)
- `npm run lint` + `npm test` + `npm run build` green
- Push → auto-deploy → re-verify on the live URL
- Deliver: bug table (found → fixed), anything deferred listed explicitly

## Bound
- Fixes limited to bugs/UI defects found in the audit — no new features beyond small UX repairs
- Demo-mode safe: no real-money flags touched
